# 🏨 Hospitality Analytics Dashboard

## 📌 Project Overview

The Hospitality Analytics Dashboard is an interactive Power BI project developed to analyze hotel business performance. The dashboard helps management monitor revenue, occupancy, booking trends, and customer behavior to support data-driven decision-making.

---

## 🎯 Objectives

- Analyze hotel revenue and occupancy.
- Track booking performance across hotels.
- Monitor ADR (Average Daily Rate) and RevPAR.
- Identify trends and business opportunities.
- Provide interactive reports for stakeholders.

---

## 🛠️ Tools & Technologies

- 📊 Power BI
- 🗄️ MySQL
- 📈 Microsoft Excel
- 🔄 Power Query
- 🧮 DAX
- 📁 CSV Dataset

---

## 📈 Key Performance Indicators (KPIs)

- 💰 Total Revenue
- 🏨 Occupancy %
- 💵 ADR (Average Daily Rate)
- 📊 RevPAR (Revenue Per Available Room)
- 🛏️ DSRN (Daily Sellable Room Nights)
- ✅ Realisation %
- ❌ Cancellation Rate
- ⭐ Average Customer Rating

---

## 🔍 Key Insights

- Identified the highest revenue-generating hotels.
- Compared occupancy across different cities.
- Monitored weekday vs weekend booking performance.
- Analyzed cancellation trends to identify revenue loss.
- Evaluated customer ratings to improve service quality.
